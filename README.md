# BMHCOACING Multi-Agent Healthcare Workspace

This repository contains an initial multi-agent project scaffold for:
- A secure Node.js middleware relay between mobile diagnostics and FHIR EHR.
- A unified dashboard UI mock-up for in-home visits + RPM feeds.
- A Codex Skill (`Healthcare-Secure`) that enforces endpoint security controls.
- CI automation for feature branches (security scan, tests, markdown diff report).
- A Python scheduling optimization + Folium mapping tool.
